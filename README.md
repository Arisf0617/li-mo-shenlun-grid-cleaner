# 留墨：申论卷面去红格

留墨是一款离线图片工具，尝试去除答题纸上的红色印刷格线，同时保留原始手写笔迹的位置、形状和行文布局。它不使用 OCR，不识别或重建文字；图片像素只在本机浏览器或 Android 应用中处理。

## 下载与运行

- **Android**：从 GitHub Releases 下载 `留墨-Android.apk`，在 Android 8.0 或更新版本安装。Android 16 可用。若系统拦截侧载，请在系统设置中允许当前安装来源。
- **Windows、macOS、Linux**：下载 `留墨.html` 并用最新版 Chrome 或 Edge 打开。该文件独立运行，无需安装、服务器或网络连接。
- **源码运行**：打开 `index.html`。可选择、拖入或粘贴 JPG、PNG、WebP、BMP 图片；手机浏览器支持时也可直接拍照。处理完成后导出 PNG。

## 功能

- “仅去红格”模式尽量保留非目标像素；“白纸阅卷”模式会额外调整纸面色调和明暗。
- 左右旋转 90 度只改变预览与导出方向，不重复图像分析，也不会清除局部修正。
- 选择局部保护或清除时自动显示范围覆盖：橙色为算法去格区、蓝色为手动保护区、玫红为手动清除区；覆盖色只用于编辑预览，不会进入导出图片。
- 提供原图对照、缩放、局部笔迹保护、残线清除与撤销。
- Android 版可调用系统相机拍摄，并将 PNG 保存到系统相册。
- 图像大小上限为 1600 万像素。高分辨率照片占用较多内存，速度因设备而异。

## 图像保真说明

算法根据颜色和局部线条特征估计印刷格线，再恢复线条位置的纸面颜色；它不二值化、生成或替换字符。暗色手写线条优先保护。白纸模式会改变灰度和纸面颜色；如需尽量保持原始色调，请选择“仅去红格”。

格线与淡笔迹重叠、照片严重模糊或光线不均时，单张照片无法保证完全分离。红色笔迹也可能被当作格线处理。建议使用原图对照放大检查，并用“保护笔迹”修复细节。任何模式都不能保证对所有照片做到格线全无且每个手写像素绝对不变。

## 隐私

程序不调用 OCR 或网络服务，也不上传图片。浏览器版在页面内存中处理；Android 版通过系统相机、照片选择器和本地 WebView 工作。公开源码仓库与发布 APK 不包含用户卷面样例或本机验证截图。

## 从源码构建

独立网页：

```powershell
python tools/build_portable.py
```

Android Debug APK（需要 JDK 17+、Android SDK Platform 35 与 Build Tools 35）：

```powershell
./build-apk.ps1
```

Gradle Wrapper 位于 `android-app/`。Debug APK 使用本机构建签名，适合测试与侧载，不是 Google Play 发布签名。

运行合成像素算法测试（需要 Node.js）：

```powershell
node tools/test-core.cjs
```

## 目录

- `index.html`、`styles.css`、`app.js`：浏览器界面与交互。
- `grid-core.js`：像素分析和渲染算法。
- `grid-worker.js`：后台处理入口。
- `android-app/`：Android WebView 容器和 Gradle 工程。
- `tools/`：便携 HTML、Android 资源构建脚本及合成测试。
